# Guitar Mentor AI — MVP Backlog v0.1

Источник: согласованные бизнес-принципы и Architecture v0.2. Полная декомпозиция ведётся через GitHub Issues.

## Инкременты
- **I0 / DEV-01–05:** Python setup, Telegram bot, SQLite/Alembic, ProfileService, анкета.
- **I1 / DEV-06–10:** Skills, диагностика по самоописанию, AgentService, каталог этюдов, LearningService.
- **I2 / DEV-11–16:** StorageService, приём небольших аудио, Submission/Attempt, самооценка и обратная связь, завершение по решению ученика, пересмотр программы.
- **I3 / DEV-17–19:** TTL/SystemSetting, MediaCleanupJob, сквозные тесты.
- **P1 / DEV-20–22:** S3 adapter, расширенный каталог нот/PDF/GTP, многопользовательская модель.
- **SPIKE-01:** достоверность анализа гитарного ритма по размеченным записям.
- **SPIKE-02:** генерация, проигрываемость и экспорт этюдов/табулатур.
- **SPIKE-03:** приём видео >20 МБ через веб-загрузку или локальный Bot API server.

## Первый проверяемый сценарий
`/start` → создание профиля → анкета предпочтений → сохранение в SQLite → рестарт → восстановление того же профиля.

## Приёмка MVP-1
Ученик получает индивидуальное задание, отправляет исполнение, видит источник и ограничения оценки, может повторить или принять с замечаниями и перейти к следующему уроку. История остаётся, исходный файл удаляется согласно TTL.
