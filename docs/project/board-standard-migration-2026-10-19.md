Основание — поручение владельца обновить регламенты и доски по изученным подходам. Настройки выполнены через авторизованный интерфейс GitHub Project 1; это запись фактической миграции, а не план настройки.

## Поля и представления

- Этап: Бэклог → Анализ → Оценка → Разработка → **Код-ревью** → Тестирование → Завершение. Код-ревью добавлено перед Тестированием, с описанием ожидаемой проверки.
- Status: В очереди / В работе / Ожидание / Выполнено / **На обсуждении**. Добавлено описание На обсуждении; уточнены Выполнено и Ожидание. Ни одно прежнее значение не удалено и не переименовано.
- Новое Single select **Профиль спецификации**: Full / Standard / Design / Light. Поле видно среди полей карточек «Задач»; пустые профили бэклога не заполняются предположениями. Выбор обоснован в стандарте и карточке.
- Уровень и Тип остаются отдельными полями; native parent/sub-issues сохранены. Доски Задачи/Стори/Эпики и таблица Иерархия остаются отдельными представлениями. У родителей прежние Бэклог / Разработка / Выполнено, часы и профиль задач на них не дублируются.
- Подготовка/тестирование релиза отражаются отдельным чек-листом реального выпуска; пустые релизы или новые продуктовые задачи не созданы.
