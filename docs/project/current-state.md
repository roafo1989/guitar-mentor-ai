## Что осталось для #30

Использовать ветку реализации feature/issue-30-safe-media-store / PR #69, а не QA-ветку. [Инструкция запуска](https://github.com/roafo1989/guitar-mentor-ai/blob/07cc33b99e9cc6fdbf0c9cc7dae28c1a1fab87ac/docs/development/dev-05b-media-store-acceptance.md).

1. На своей Windows-установке сверить прежние попытки после обновления, F5 и обычного перезапуска backend.
2. Настоящим микрофоном записать 5–10 секунд: разрешение, реакция уровня, слышимый черновик; до отправки новой попытки нет, после одной отправки — одна.
3. Проверить собственные установленные учебные MP3/PDF на воспроизведение/читаемость.

Остальные доступные агенту технические проверки уже исполнены независимо. Это не новая приёмка #20 и не команда реализовать #21. #30/#21/#58 остаются открытыми.
