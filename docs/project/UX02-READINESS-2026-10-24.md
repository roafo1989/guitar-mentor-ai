## 1. Найденные пробелы и принятые решения

- У147 не было native sub-issues, в148–152 стояло `#undefined`. Исправляется связь148–152→147→53, повторные Issues не создаются.
- Пустые уровень/этап/тип/профиль и отсутствие оценок не означают готовность к коду. Поля задаются по фактической подготовке и проверяются обратно.
- Новая концепция двух колонок учитывает принятый полноширинный PDF из51: две колонки только от1100px, score занимает больше60%; иначе один столбец, есть режим сосредоточенного чтения.
- Home summary — frontend resolver, не новый REST. Bare learner после свободной регистрации сначала проходит профиль, ошибки не маскируются отсутствием данных.
- Текущий native PDF iframe не даёт приложению надёжный zoom/pagination. В150 описан изолированный lazy canvas reader с точными ресурсами по версии, controls, ошибками и native fallback.
- Запись и инструменты остаются singleton/stateful компонентами; resize, открытие нот и адаптивная вёрстка не размонтируют черновик. Метроном во время записи разрешён, тюнер не прерывает запись.
- Проценты прогресса, streak и ИИ-советы из концепта не переносятся в UI как настоящие.152 использует реальные assessment/decision/evidence состояния.
- Для несуществующего пока `/library` не добавляется активная ссылка. Это будущий163, не блокер shell148.
