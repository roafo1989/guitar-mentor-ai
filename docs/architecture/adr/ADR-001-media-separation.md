# ADR-001 — Разделение метаданных и медиа

**Статус:** принято как архитектурное направление.

## Контекст
Ученик загружает аудио, видео и нотные документы. Объём бинарного контента может быть значительно больше структурированных данных.

## Решение
Не хранить исходные файлы в SQL BLOB. В реляционной БД хранятся MediaAsset, владелец, тип, размер, статус, storage key, время жизни и связи с PerformanceSubmission/Assessment. Бинарный контент — в хранилище за интерфейсом StorageService. Для MVP — локальная файловая система; в дальнейшем — S3-compatible object storage.

## Следствия
- Приватный доступ; никаких публичных постоянных URL; проверка владельца.
- Отдельная обработка частично успешных операций БД/хранилища и уборка orphan-файлов.
- Метаданные и история оценок сохраняются после удаления временных исходников.
- Нельзя смешивать пользовательские исходники с проверенными учебными материалами.
