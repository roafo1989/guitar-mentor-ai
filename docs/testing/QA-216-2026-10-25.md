## Дефекты, найденные и исправленные при QA

1. **P1 — старый browser key удалялся до успешного authoritative current GET** для ARCHIVED; при offline/500 пользователь терял восстановление. Исправлено и покрыто отдельными тестами.
2. **P1 — Vue компиляция после повторного запроса:** plain `pendingRequest` использовался как template-reactive; typecheck упал. Переведено на `ref`, CI восстановлен.
3. **P2 — разная целевая композиция после неопределённого POST:** теперь сохраняется исходный requestId/payload до определённого исхода, вводится подтверждение явного повтора упражнения.
4. **P2 — overflow истории при 200% effective zoom:** Chrome зафиксировал `layout=180, scroll=263`; добавлены переносы и ограничение ширины, повторный Chrome CI пройден.
5. **P3 — smoke runner скрывал первую ошибку из-за ENOTEMPTY при очистке профиля Chrome:** cleanup исправлен; реальные ошибки теперь видны в логах.

## Условия независимой приёмки / ограничения

Нет доступа из CI к локальному `https://guitar-mentor`, живому пользовательскому аккаунту, микрофону, авторизационным переходам и реальным media fixtures. Поэтому полное прохождение всех 24 TC **не подтверждено**. Нельзя проставить всем `PASSED`, объявить независимое QA, сливать PR или закрывать #216 только на основании зелёного CI.

Для окончательной продуктовой приемки на пользовательском стенде необходимы сценарии complete → choose → real next → old history; logout/login/F5, запись/медиа TTL, mobile+keyboard, rollback/upgrade rehearsal. Зафиксировать дату/коммит и результаты в этом отчёте, а оригинальный [TC](TC-LESSON-NEXT-01.md) оставить NOT_RUN там, где подтверждения нет.
