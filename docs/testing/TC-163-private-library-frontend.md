# TC-163 — Личная библиотека PDF / Guitar Pro (Vue)

Версия: 2026-10-25. История US-011/#155, задача #163. PR #208.

## Контракт и окружение
Личный интерфейс `/library` использует готовые owner-scoped backend endpoints задач #160, #161, #162. Включить `guitar-mentor.library.enabled=true`, рабочий приватный library storage root, cursor-secret длиной не менее 32 байт; пользователь должен быть допущен и авторизован. Без этого UI показывает серверную ошибку/отключение, **не** имитирует успешную загрузку. Для ручных проверок использовать только одноразовые материалы, а не импортированный музыкальный архив.

## Выполненные автоматические проверки

- CI фронтенда: `npm test` с `private-library.test.mjs`, `vue-tsc` + Vite, Light Minimal build, Chrome smoke — финальный статус сверить с PR #208.
- Backend-функциональность POST/PATCH/DELETE/GET уже разработана/проверена в #160–162, здесь backend не модифицируется.
- Этот набор не заменяет реальный UAT upload/download/delete: соответствующие строки остаются **NOT_RUN**, пока не проведены под учётной записью на локальном сервере.
- User story #155 остаётся открытой до E2E #164.

## Ограничения
Приватная библиотека — не общий каталог публикаций; чтение чужих разрешённых опубликованных материалов будет в US-012 (#156/#165/#166). Пользовательские загрузки не публикуются автоматически. Поскольку backend не предоставляет upload percent events, UI показывает indeterminate busy progress, но не выдумывает проценты. Прямое скачивание выполняется через авторизованный API, без сторонних URL.
