# TC-170D — Интерфейс конвертации Guitar Pro

**Связанные задачи:** #170, #263  
**Реализация:** PR #264  
**Дата:** 01.11.2026  
**Статус:** подготовлены; browser/manual execution — после включения conversion flag в изолированном тестовом окружении с завершённым 170-E.

## Предусловия

- Пользователь авторизован и открыт раздел «Моя библиотека».
- В личном материале есть оригинальные SCORE_ORIGINAL в READY.
- Для UI/API контрактных проверок используются mocked responses; запуск реального renderer не является частью 170-D.
- Feature flag в обычном окружении остаётся выключенным.

## Проверки

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-170D-01 | Материал содержит READY GP3 | Действие конвертации доступно только в деталях личного материала. |
| TC-170D-02 | Материал содержит READY GP4 или GP5 | Действие конвертации доступно. |
| TC-170D-03 | Файл GPX, GP7/GP8, PDF, GTP, фото или запись | Действие конвертации не показывается; скачивание оригинала остаётся доступным. |
| TC-170D-04 | SCORE_ORIGINAL находится не в READY | Действие конвертации не показывается. |
| TC-170D-05 | Запуск конвертации | POST содержит sourceAssetId, новый UUID Idempotency-Key и If-Match revision материала. Повтор того же запроса использует тот же ключ. |
| TC-170D-06 | API возвращает QUEUED/RUNNING | Отображаются состояние, этап и прогресс; состояние периодически обновляется. |
| TC-170D-07 | API возвращает AWAITING_TRACK_SELECTION с несколькими гитарными дорожками | Показан список только гитарных дорожек; без явного выбора продолжить нельзя; первая дорожка автоматически не выбирается. |
| TC-170D-08 | Выбор дорожки | POST отправляет trackIndex и актуальный If-Match job revision; состояние возвращается к очереди. |
| TC-170D-09 | Отмена QUEUED/AWAITING_TRACK_SELECTION | Отправляется cancel; после ответа показывается CANCELLED. |
| TC-170D-10 | Отмена RUNNING | Показывается запрос остановки; итоговый CANCELLED отображается только после ответа сервера. |
| TC-170D-11 | FAILED/TIMED_OUT, retryable=true | Доступна кнопка повтора; retry отправляет актуальный If-Match. |
| TC-170D-12 | FAILED/UNSUPPORTED/CANCELLED/SUCCEEDED либо retryable=false | Повтор недоступен. |
| TC-170D-13 | Перезагрузка той же вкладки при активном job | Job ID восстанавливается из account/material-scoped sessionStorage; UI получает актуальное состояние через GET. |
| TC-170D-14 | Временная ошибка GET | Ошибка понятна пользователю; job не теряется, polling повторяется с увеличенным интервалом. |
| TC-170D-15 | Уход со страницы или смена пользователя | Таймер очищается, запрос прерывается; старый ответ не меняет новый экран. |
| TC-170D-16 | SUCCEEDED с обоими asset IDs | UI загружает свежую карточку и сверяет DERIVED_SCORE_PDF + SYNTHESIZED_PREVIEW; PDF открывается штатным просмотрщиком, WAV — штатным аудиоплеером. |
| TC-170D-17 | SUCCEEDED без одного из двух файлов | UI не объявляет результат готовым; отображает ошибку проверки результата. |
| TC-170D-18 | Сервер отвечает 503 из-за выключенного feature flag | Показано сообщение о временной недоступности; оригинал остаётся доступным. |
| TC-170D-19 | Сервер возвращает неизвестный machine code или текст с путём/stack trace | В интерфейсе не отображаются произвольный текст, локальные пути и stack trace. |
| TC-170D-20 | Открыть опубликованный материал в общей библиотеке | Действие конвертации отсутствует. |
| TC-170D-21 | Сменить язык RU/EN | Все статусы, этапы, ошибки, кнопки и пояснение scope локализованы. |
| TC-170D-22 | Управление только клавиатурой и мобильная ширина | Радио-выбор, кнопки и прогресс доступны с клавиатуры; панель не вызывает горизонтальную прокрутку. |

## Автоматизация

- `frontend/tests/conversion-ui.test.mjs`: DTO validation, owner-scoped URLs/headers, create/get/track-selection/cancel/retry, allow-listed machine codes, RU/EN copy, private-only integration и lifecycle contract.
- `npm test`: включает новый conversion UI test.
- `npm run build`: Vue typecheck и production build.

## Ограничения тестирования

Реальный запуск конвертации из UI не считается доказанным в 170-D: durable worker orchestration, Windows Docker Desktop, расширенный musical/adversarial corpus и resource/fault gates относятся к 170-E. Feature flag не включать до закрытия этих gates.
