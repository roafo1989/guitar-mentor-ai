## Что поставляется

Только оригинальный Vue presentation A и CSS/tokens, зарегистрированный в статическом allowlist. Общие controls/controller/actions из113. Никаких копий Web Audio, таймеров, BPM validation, preset CRUD, API, БД, AI, анализа записи, permission или network. Селектор и сохранение skinId — отдельная115; C —116. При таком влиянии Design достаточен: новая пользовательская логика не добавляется.

Центральный круг/дуга — **композиция**, а не обязательное колесо ввода. В центре всегда обычный доступный input BPM20–240 с видимым label. «−» и «+» физически разнесены, шаг1, каждая зона44×44CSSpx; drag/вращение не требуются. Start/Stop, Tap, размер/единица, линия долей, входы в настройки/пресеты находятся на основном экране. Число долей/динамическая группировка выводятся через shared controls, геометрия круга не задаёт4/4.

Mobile360×640 при100%: основной сценарий виден целиком. Settings/presets отдельной панелью по111. Desktop остаётся компактным, без растягивания пустого круга. При200%zoom/большом шрифте допустима вертикальная прокрутка, все controls остаются достижимы; горизонтальной нет. Точный радиус/высота/spacing и акцентные цвета выбираются в макете до кода; не выдаются за уже согласованные числа.

## Контракт состояния и действий

A получает ту же read-only view model и actions, что B. Обычные пользовательские editBpm/step/tap/start/apply/presets вызывают общие команды. Mount/unmount A не вызывают engine.start/stop/setBpm/apply/store. В A нет собственного controller или watcher, сбрасывающего формы. Бизнес-правила raw invalid input, pending на следующем такте, немедленного BPM reset, master и preset validation остаются в113/104.

| Состояние | Представление |
| --- | --- |
| ready/stopped | Нейтральная дуга, BPM edit, явный Start; не имитировать звучание |
| starting | Честное ожидание; повторный Start не активен |
| running | Нота/доля/дуга следуют текущему engine snapshot, не декоративному независимому ритму |
| pending/draft | Различимы звучащий и ожидающий/редактируемый паттерн; Apply и текст поясняют границу |
| invalid | Исходный текст видим, error рядом, общие disabled правила; не менять молча BPM |
| settings/presets/confirm | Те же данные и команды, фокус/возврат/закрытие панели как в B |
| unavailable/storage failure | Прежние RU/EN сообщения и доступное действие повтора; красота не скрывает ошибку |

Фокус управляется shell/binding из113; A предоставляет стабильные логические control IDs и DOM refs для BPM/панелей. Цвет дополняется подписью/формой; видимый focus, keyboard labels и reduced motion обязательны. Не объявлять каждую долю screen reader сотни раз. No v-html, внешних URL/ассетов или произвольного runtime CSS. Применимы NFR-004/008 и SEC-005/008; новых прав/секретов/логов нет.
