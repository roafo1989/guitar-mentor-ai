# BUG-095 — Сохранение языка интерфейса

## Паспорт, основание и ценность

Профиль **Standard**: изменение запуска общего интерфейса и браузерного хранения. Issue [#95](https://github.com/roafo1989/guitar-mentor-ai/issues/95), родитель US-003/#57, EPIC-001/#53. База: БТ 0.4 / BT-012, ТЗ 0.9 / FT-003-02, NFR-004; SEC-005/008. Это исправление существующего RU/EN интерфейса, не новая система локализации. Источник — TC21-13: после выбора EN и F5 возвращается RU.

Как ученик, я хочу сохранять выбранный язык после перезагрузки, чтобы не переключать его перед каждым занятием. Исходный дефект подтверждён статическим чтением main `da7488c97136a02ffd69051d04dbea0cd6c0638c`: `frontend/src/core/i18n.ts` задаёт `locale: 'ru'`; `App.vue` содержит только `v-model="locale"`.

## Границы и зависимости

Сохранить существующие RU/EN, fallbackLocale EN, переключатель хедера и работу Vue Router. Входит один механизм чтения/сохранения локали и регрессия общего интерфейса. Не входят серверная настройка профиля, новые языки, выбор по геолокации/языку ОС, синхронизация вкладок, исправление всех старых переводов. Зависимостей от #15/#18/#19 и музыкального корпуса нет. Перед реализацией сверить `App.vue` с незавершёнными #87/#98; не удалять кнопки инструментов или обработку аудио.

## Решение и контракт

| Элемент | Правило |
| --- | --- |
| Ключ | `guitar-mentor.locale`, localStorage того же origin |
| Значение | Строка строго `ru` или `en`; другие значения не исполнять и не интерпретировать как код |
| Нет/невалидное значение | RU, без ошибки запуска и без автоматического определения языка |
| Чтение | Синхронно до `createI18n`/первого mount, чтобы сохранённый EN не начинался с промежуточного RU |
| Запись | При фактической смене поддерживаемой локали, один общий обработчик; не регистрировать новые watcher при каждом переходе |
| Недоступное хранилище | Обернуть получение объекта localStorage, getItem и setItem в обработку исключений; смена языка работает в памяти до закрытия приложения |
| Область | Локальная настройка браузера на origin, общая для выбранных учеников на этом устройстве; API и БД не участвуют |

Рекомендуемое размещение: небольшой модуль в `frontend/src/core`, используемый инициализацией i18n; header остаётся потребителем общей locale. Чистую нормализацию/доступ к storage проверить с подставным хранилищем. На сервере, где нет `window`, используется RU. Пустая строка, `EN`, JSON и произвольные строки считаются невалидными. Не очищать другие ключи localStorage. После сетевой ошибки или смены ученика выбранный язык остаётся тем же.

## Ошибки, НФТ и безопасность

Новая сетевая операция, разрешение браузера, секрет, миграция или сервис не нужны. В storage сохраняется только код языка; имена, записи, токены и идентификаторы ученика не добавляются. NFR-004 проверяется восстановлением после F5 и отсутствием сброса формы при переключении; числовой SLA не вводится. SEC-008 — allow-list значений, SEC-005 — отсутствие пользовательских данных в новых логах. Ошибка storage не требует модального предупреждения: интерфейс продолжает работать, не маскируя ошибки REST/записи. При диагностическом логе допустим только код `LOCALE_STORAGE_UNAVAILABLE`, без содержимого storage.

## Сценарии приёмки (ожидаемые, не результаты тестирования)

- **AC95-01:** Дано: storage пуст. Когда: приложение открыто. Тогда: RU и существующая навигация доступны.
- **AC95-02:** Дано: выбран EN. Когда: выполнены переход между разделами и F5. Тогда: селектор и переводы остаются EN без повторного выбора.
- **AC95-03:** Дано: сохранён EN. Когда: выбран RU и выполнен F5. Тогда: восстановлен RU.
- **AC95-04:** Дано: в ключе неподдерживаемая строка. Когда: приложение запущено. Тогда: RU, нет исключения и выполнения содержимого строки.
- **AC95-05:** Дано: доступ/getItem/setItem выбрасывает исключение. Когда: приложение открывается и язык меняется. Тогда: нет падения; язык меняется в памяти, F5 безопасно использует RU, если чтение всё ещё недоступно.
- **AC95-06:** Дано: есть профиль, сессия и черновик. Когда: язык изменён без перезагрузки. Тогда: они не сбрасываются, повторного POST/запуска микрофона нет; прежние механизмы F5/предупреждения о несохранённой записи не меняются.

Проверки разработчика: нормализация/отказы storage, проверка header+i18n, production build, существующие intake/metronome/tuner тесты по фактическому main и ручной EN → F5 → RU → F5 на локальном HTTPS. Обновление текущего анализа не означает их выполнение.

## Установка, smoke и откат

Поставляется обычной сборкой frontend. Smoke: открыть diagnostics, выбрать EN, F5, перейти в профиль, вернуть RU, F5; сохранённый ученик и сессия доступны. Отдельные env/config/права не добавляются. Откат при ошибке запуска/потере формы: владелец локальной установки возвращает предыдущую сборку frontend; ключ языка можно удалить отдельно, другие ключи не трогать. После отката подтвердить доступность страниц и стандартный RU; данных для восстановления в БД нет, поскольку они не изменялись.
