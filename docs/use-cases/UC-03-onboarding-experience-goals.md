# UC-03 — Музыкальный опыт и цели ученика (DEV-04)

**Статус:** первая проектная реализация; требования уточняем по результатам пользовательского тестирования.

## Контекст
UC-01 сохраняет инструмент, технику и музыкальные предпочтения. UC-03 дополняет профиль информацией для персонализации учебной программы, но **не определяет объективный уровень навыков**. Последующий UC-02 выполняет диагностику.

## Бизнес-данные
- Самооценка уровня: NONE/BEGINNER/INTERMEDIATE/ADVANCED.
- Полные годы занятий: 0–60 (для новичка 0; округление пока допустимо).
- Освоенные техники (множественный выбор): CHORDS/STRUMMING/ARPEGGIOS/FINGERSTYLE_MELODY.
- Разученные произведения: название, автор, не более 10; могут отсутствовать.
- Учебные цели: FINGERSTYLE/RHYTHM/INDEPENDENT_BASS/DIFFERENT_STYLES/COMPOSITIONS/THEORY.
- Доступное время на занятие: 10–120 минут; занятий в неделю: 1–7.
- Свободный комментарий: до 1000 символов.

## Сценарий
1. Из карточки ученика переход к «Мой опыт и цели».
2. Шаг «Опыт»: уровень, стаж, техники и произведения. Новичок может оставить ноль, все списки пустыми.
3. Шаг «Цели»: направления, время, комментарий.
4. По нажатию «Сохранить» клиент делает PUT на API.
5. Повторный вход выполняет GET и восстанавливает значения из PostgreSQL.
6. Ученик может изменять анкету без потери профиля или предыдущего списка музыкальных предпочтений.

## REST-контракт
`GET /api/v1/learners/{learnerId}/instruments/{instrumentCode}/background`: 200 с анкетой, 204 если ещё нет; 404 если нет ученика или инструмент не принадлежит ему.

`PUT /api/v1/learners/{learnerId}/instruments/{instrumentCode}/background`: idempotent upsert — сохраняет анкету; повторный PUT изменяет существующую запись.

Тело PUT:
```json
{
  "experienceLevel": "INTERMEDIATE",
  "yearsPlaying": 4,
  "skills": ["CHORDS", "ARPEGGIOS", "FINGERSTYLE_MELODY"],
  "knownPieces": [{"title": "Yesterday", "artist": "The Beatles"}],
  "goals": ["FINGERSTYLE", "RHYTHM"],
  "practiceMinutes": 40,
  "sessionsPerWeek": 3,
  "notes": "Хочу освоить разные стили без медиатора"
}
```

## Ограничения
- Самооценка не равна результату диагностики; соответствующие поля разделены.
- Свободный текст может быть пустым.
- Нет встроенной загрузки файлов, уточняющих ИИ-вопросов или LLM-планирования — следующие итерации.
- Нет аутентификации и авторизации. **Запуск разрешён только локально на loopback с тестовыми данными.** Доступ по UUID не является механизмом безопасности.

## Критерии приёмки
- AC-O01: пользователь NONE/0/пустой репертуар проходит анкету.
- AC-O02: GET после PUT показывает те же данные.
- AC-O03: изменение анкеты не создаёт новую background-запись.
- AC-O04: запрос к чужому instrument-profile недоступен при данном learnerId.
- AC-O05: недопустимые значения отвергаются (400).
- AC-O06: сохранение не изменяет musical preferences из UC-01.
