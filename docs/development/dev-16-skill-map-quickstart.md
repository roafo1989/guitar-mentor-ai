## Ручная проверка для владельца / тестировщика

1. Создать локального тестового ученика (использовать только вымышленные данные) с `ACOUSTIC_GUITAR / FINGERSTYLE`. Сохранить анкету `INTERMEDIATE`, 45 минут/занятие, цель RHYTHM; стиль BLUES поставить LIKE.
2. Перейти в «Диагностика», «Продолжить без записи». На этапе `READY_FOR_TASK` появляется блок рекомендаций: `GM-EB01 v0.8B`, 30 минут, навыки PULSE/BASS_PULSE/MELODY и причины. Кнопка «Назначить» ещё не нажата: на сервере `GET .../tasks` должен быть 204.
3. Обновить страницу (F5): объяснимый подбор воспроизводится; диагностическое задание не создаётся от GET.
4. В профиле заменить предпочтение BLUES на EXCLUDE; вернуться на диагностику. При текущем одном этюде ожидать `NO_MATCH / ALL_STYLES_EXCLUDED`, без автоматического назначения. Ручной каталог остаётся виден. Вернуть NEUTRAL/LIKE для дальнейшей проверки.
5. Для другого тестового ученика сохранить NONE/BEGINNER или вообще не сохранять анкету. Текущий GM-EB01 (INTERMEDIATE) не должен предлагаться автоматически. Ожидается `NO_MATCH / NO_BEGINNER_EXERCISE`. При появлении beginner-упражнения из #17 — проверить новую ветку.
6. Для промежуточного ученика выбрать рекомендацию: один `DiagnosticTask`, прежние ноты/preview и отправка аудио доступны. Повторный клик не создаёт вторую запись.
7. Проверить `GET /api/v1/learners/{learnerId}/instruments/ACOUSTIC_GUITAR/skills`: девять навыков, предпосылки, `assessedLevel=0` и `NOT_ASSESSED` при отсутствии подтверждённых данных. Добавить в анкету FINGERSTYLE_MELODY, сохранить два раза и убрать: история `GET .../skills/history?skillCode=MELODY` получает только события фактических изменений `CLAIMED`, `RETRACTED`.
8. Чужой learnerId или sessionId должен давать 404 (без раскрытия другого ученика), `COLLECTING_EVIDENCE` и `TASK_ASSIGNED` — 409; `limit=0/4` — 400. Нет постороннего изменения хранилища записей.
9. Проверить обе локализации интерфейса (ru/en), состояния ошибки сети, повторной загрузки и отсутствие принудительного выбора.

## Ограничения

- Проверенный уровень навыка из SELF_REPORTED не возникает. Ручная/автоматическая Assessment-история, StudentDecision и подтверждённые пробелы — #18/#22; адаптивные следующие уроки — #24.
- Новых музыкальных материалов и полноценного beginner-этюда в #16 нет: наполнение и музыкальное ревью — #17.
- Не считать красивое отображение нот свидетельством музыкальной приёмки.
- Выше описаны **ожидаемые результаты**, не протокол фактически пройденной локальной проверки.

## Отмена / откат

При дефекте остановить развёртывание и вернуться к предыдущему совместимому коду. Только после согласованного восстановления из резервной копии при подтверждённой несовместимости. Исходные медиа эта задача не меняет.
