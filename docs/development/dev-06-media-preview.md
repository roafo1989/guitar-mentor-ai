# DEV-06 — Предпросмотр этюда (PDF и MP3)

## Контракт
До назначения студент может прослушать аудио и просмотреть ноты+TAB в PDF без создания DiagnosticTask. После назначения оба медиа остаются на экране урока. Браузерный HTML5 player / iframe + ссылка открыть PDF в новой вкладке. Музыкальные примеры v0.8B синтезированы; не выдавать их за исполнение преподавателя.

## Хранение
Flyway V6 добавляет exercises.preview_audio_resource / preview_pdf_resource. В PostgreSQL хранятся лишь **версионированные пути**. PDF/MP3 обслуживает backend:
- GET/HEAD /api/v1/exercises/GM-EB01/preview/audio — audio/mpeg
- GET/HEAD /api/v1/exercises/GM-EB01/preview/pdf — application/pdf
- Если медиа ещё не установлены — 404, а frontend показывает понятное сообщение и ссылку на MusicXML.

На первом этапе медиа находятся локально в Java classpath. Позднее выделим хранилище учебного контента, отдельное от личных записей учеников.

## Новая редакция PDF по замечанию к интерфейсу

- PDF v0.8B переразложен **по 4 такта в строке**; всего **3 системы / 12 тактов / 1 страница A4**. Каждая система содержит нотный стан и 6-линейную табулатуру с общими вертикалями тактов; ориентир — предоставленный учеником `ex2.pdf`.
- Музыкальные события и MusicXML не менялись: это **правка верстки, не новая музыкальная версия**.
- Упрощённая ASCII-TAB под PDF **удалена** из `DiagnosticView.vue`, поскольку дублирует полноценную партитуру, и музыкальные интервалы изображала лишь приблизительно.
- Обновлённый архив называется `guitar-mentor-dev06-preview-media-v08B-4bars.zip`. Внутри прежний `preview_v08B.mp3` и **новый** `score_v08B.pdf`; имена и пути файлов для backend остаются прежними, менять Flyway V6 и API не требуется.
- После назначения заголовок блока меняется на «Материалы задания», вместо фразы «перед выбором»; дополнительная дублирующая ссылка MusicXML удалена.
- Ручная проверка необходима в браузере и на распечатке. Проверено, что PDF содержит ровно 1 страницу и все 12 тактов.

## Установка Windows
В чате доступен ZIP: **guitar-mentor-dev06-preview-media-v08B-4bars.zip**. Внутри обновлённый PDF (1 страница, по 4 такта в строке) и прежний MP3 (~36 с).
1. Обновить ветку `main`: `git switch main`, затем `git pull --ff-only`. Если Git сообщает о локальных изменениях — не перезаписывать их, сначала разобраться с ними. Остановить Spring Boot Ctrl+C.
2. Сохранить ZIP в D:\Development.
3. Распаковать в корень репозитория:
```powershell
Expand-Archive -Path "D:\Development\guitar-mentor-dev06-preview-media-v08B-4bars.zip" `
  -DestinationPath "D:\Development\guitar-mentor-ai" -Force
```
4. Убедиться, что файлы по путям:
```text
D:\Development\guitar-mentor-ai\backend\src\main\resources\exercises\GM-EB01\preview_v08B.mp3
D:\Development\guitar-mentor-ai\backend\src\main\resources\exercises\GM-EB01\score_v08B.pdf
```
5. Перезапустить backend, открыть https://guitar-mentor/diagnostics и обновить Ctrl+Shift+R.
6. Проверить аудио/все страницы PDF **до** назначения, затем после назначения и F5.

Медиа локально исключены из Git через .gitignore и пока не включены в публичный PR. По умолчанию CI проверяет код и миграции, а ручная медиа-проверка выполняется после установки ZIP. PR #49 уже объединён в `main`; ручная приёмка нового PDF, плеера и назначения пока не подтверждена. Слияние не означает завершение всего Issue #17. После подтверждения обновления версии владельцем карточка переводится в «Тестирование / В очереди».
