## Локальная проверка

1. На Windows: git fetch origin; git switch feature/issue-68-diagnostic-evidence; git pull --ff-only. Если ветки ещё нет локально, используйте git switch --track origin/feature/issue-68-diagnostic-evidence.
2. Запустить PostgreSQL. В каталоге backend выполнить mvn spring-boot:run; Flyway применит V12 после V10/V11.
3. Разрешить только локальные тестовые загрузки установкой GUITAR_MENTOR_ENABLE_UPLOADS=true. По умолчанию отключено. Настоящие личные медиа не использовать до реализации авторизации #38.
4. Внутренние каталоги: GUITAR_MENTOR_MEDIA_PATH для аудио и GUITAR_MENTOR_SCORE_PATH для PDF/JPG/PNG (по умолчанию ./.local-media/attempts и ./.local-media/scores). Доступа к сырым файлам по HTTP нет.
5. Нужен ffprobe из FFmpeg в PATH для проверки длительности и целостности аудио; можно задать GUITAR_MENTOR_FFPROBE.
6. В frontend выполнить npm ci и npm run dev; открыть локальное приложение через настроенный HTTPS URL.

## API для Postman

Префикс: /api/v1/learners/{learnerId}/diagnostic-sessions/{sessionId}/evidence

GET /capabilities: флаг enabled, форматы и лимиты.
GET /: список EvidenceView без storage_key/путей/байтов.
POST /: multipart с requestId UUID, title строка до 200, composer опционально, comment опционально, audio file обязательно, score file опционально. Новый пример 201, повтор с прежним requestId 200, без новой записи.
Ошибки: 400 для форматов/лимитов и обязательных параметров, 403 отключено, 404 чужая сессия, 409 неверное состояние/лимит примеров.
