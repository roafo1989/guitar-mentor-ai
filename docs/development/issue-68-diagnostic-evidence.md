## Локальная проверка

1. На Windows: git fetch origin; git switch -C feature/issue-68-diagnostic-evidence origin/feature/issue-68-diagnostic-evidence. Ветка перенесена на актуальный main с переписанной историей; не делать обычный pull поверх локальной старой версии.
2. Запустить PostgreSQL. В каталоге backend выполнить mvn spring-boot:run; Flyway применит V13 после V10/V11 и V12 задачи #16.
3. Разрешить только локальные тестовые загрузки установкой GUITAR_MENTOR_ENABLE_UPLOADS=true. По умолчанию отключено. Настоящие личные медиа не использовать до реализации авторизации #38.
4. Внутренние каталоги: GUITAR_MENTOR_MEDIA_PATH для аудио и GUITAR_MENTOR_SCORE_PATH для PDF/JPG/PNG (по умолчанию ./.local-media/attempts и ./.local-media/scores). Доступа к сырым файлам по HTTP нет.
5. Нужен ffprobe из FFmpeg в PATH для проверки длительности и целостности аудио; можно задать GUITAR_MENTOR_FFPROBE.
6. В frontend выполнить npm ci и npm run dev; открыть локальное приложение через настроенный HTTPS URL.

## Тестирование владельцем

- Новичок: создать диагностическую сессию, не добавлять записи, сразу перейти к заданиям. Никакого штрафа навыкам.
- Загрузить запись знакомого произведения с названием, необязательным автором и PDF; прослушать перед отправкой. Убедиться, что появился один элемент с двумя материалами.
- Добавить вторую запись без PDF; F5: два отдельных элемента, стабильные названия, статус только технический.
- Перейти к заданиям: форма добавления скрыта, история остаётся доступна для чтения; прежние назначенные упражнения и попытки работают.
- Пустой/ложный PDF, перелимитный файл, 11-й пример и отключённые uploads отклоняются безопасно; продолжение без записи остаётся.
- Настоящий микрофон/отмена записи/прослушивание и очистка имени file input проверяются вручную.
- TTL из #21 удаляет аудио и ноты через 48 ч после финализации, но не удаляет название, метаданные и учебный каталог. Тестировать управляемым Clock или тестовыми timestamp.

## API для Postman

Префикс: /api/v1/learners/{learnerId}/diagnostic-sessions/{sessionId}/evidence

GET /capabilities: флаг enabled, форматы и лимиты.
GET /: список EvidenceView без storage_key/путей/байтов.
GET /{evidenceId}: один принадлежащий сессии пример по Location после POST.
POST /: multipart с requestId UUID, title строка до 200, composer опционально, comment опционально, audio file обязательно, score file опционально. Новый пример 201, повтор с прежним requestId 200, без новой записи.
Ошибки: 400 для форматов/лимитов и обязательных параметров, 403 отключено, 404 чужая сессия, 409 неверное состояние/лимит примеров.

## Поправки после код-ревью 20.10.2026

- **P1 защита черновика:** дочерняя панель немедленно отправляет родителю агрегированное состояние active record/upload и локальных изменений; «Перейти к заданиям» недоступно при записи/загрузке, а несохранённый материал требует подтверждения отказа. При ошибке POST файлы и requestId остаются для безопасного повтора.
- **P1 отсутствие starvation TTL:** 25 повторных попыток удаления и до 50 впервые просроченных файлов выбираются независимыми SQL-запросами, с упорядочиванием повторных попыток по минимальному `delete_attempts`. Регрессионный PostgreSQL-тест создаёт 60 DELETE_PENDING и 1 новый expired; доказывает выбор нового и прогресс среди pending.
- **Интеграция:** #21 принята, V10/V11 находятся в main; V13 принадлежит #68; V12 принадлежит #16. При переносе сохраняются рекомендации диагностических упражнений из #16 и обе локали. PR не объединять без нового CI и повторного ревью.

### Ручные регрессионные сценарии защиты черновика

1. Начать запись с микрофона и нажать «Перейти к заданиям» → кнопка заблокирована, рекордер остаётся открытым. Остановить запись → появляется прослушивание и подтверждение при уходе; отмена подтверждения сохраняет запись.
2. Начать отправку аудио с искусственно замедленным POST → кнопка перехода заблокирована до ответа. Ошибка POST → выбранное аудио, ноты, название и requestId сохраняются для повтора.
3. Успешно отправить аудио → после подтверждения и окончания запросов перейти к заданиям без предупреждения. После F5 список остаётся доступен только для чтения.
4. При пустой форме переход без записи сразу работает.
