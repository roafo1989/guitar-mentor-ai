## Экран урока

**До назначения:** цель и навыки, название, стиль, сложность, темп, лицензионные сведения; встроенный MP3 и встроенный PDF с нотами+TAB; действия «Открыть отдельно» и «Назначить». Просмотр **не создаёт** задание. Не требовать обязательного прослушивания.

**После назначения:** тот же материал + область «Моя работа» (аудио/видео исполнение, необязательный комментарий, отправка) + область «Обратная связь» (результат по каждому критерию, доказательства/уверенность, рекомендации, история попыток).

## Жизненный цикл

```text
ASSIGNED
  -> SUBMITTED -> PROCESSING -> FEEDBACK_READY
                            -> PROCESSING_FAILED (можно повторить обработку)
FEEDBACK_READY -> RETAKE_REQUESTED -> SUBMITTED (новая версия попытки)
FEEDBACK_READY -> LEARNER_ACCEPTED -> LESSON_COMPLETED
```
Агент рекомендует пересдачу с понятными замечаниями только при **валидированных измерениях**; ученик может принять текущий результат и продолжить **даже вопреки рекомендации агента**. Фиксировать обе позиции отдельно, не подменяя оценку «ошибок нет» желанием ученика закончить.

**Сущности** для R4: ExerciseAssignment (версия), SubmissionAttempt (n, metadata, media_id, comment), CriterionAssessment (criterion, source, confidence), FeedbackReport, LearnerDecision (RETAKE/ACCEPT_AS_IS), history. Предусмотреть повторные попытки и историю обратной связи.

**Без валидированного аудиоанализа:** статус «анализ ещё недоступен», ни фиктивных оценок ритма, ни вымышленных замечаний.

## Медиа

- Пользовательские аудио **вне PostgreSQL/Git**: в M1 приватный локальный каталог; S3 — возможное дальнейшее решение, видео ещё не реализовано. В БД только метаданные и история.
- Конфигурируемый в БД TTL — **48 часов от окончания всех этапов обработки**, не от начальной загрузки.
- После TTL удалять raw media, но сохранять записи попыток и обратной связи. Показывать «медиа удалено по политике хранения».
- Без аутентификации и проверки доступа **не разрешать реальные персональные записи** на публичном адресе.
- Учебные PDF/MP3 — **публичный/разрешённый лицензионный контент**, режим хранения отличается от личных пользовательских файлов.

## Проверки UX

1. Просмотр доступен без назначения и не создаёт запись назначения.
2. После назначения медиа в уроке не исчезают; F5 не дублирует задание.
3. Приложить MP3/видео и комментарий; студент видит дату и статус.
4. Повторить попытку, не затерев предыдущее заключение.
5. Принять результат вопреки совету, сохранив замечания.
6. После удаления медиа история оценивания остаётся.
