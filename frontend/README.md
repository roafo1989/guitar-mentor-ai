# Guitar Mentor AI — Vue frontend (DEV-03/04)

Главная страница `/` — короткое приветствие и переходы к профилю, опыту и целям, диагностике. Клик по логотипу в хедере возвращает на главную. Сохранённый профиль восстанавливается при открытии, приветствие и хедер показывают имя ученика. Тексты доступны на RU/EN; страница адаптируется к мобильному экрану. Далее: создание/чтение профиля и изменение музыкальных предпочтений, затем двухэтапная анкета опыта и целей. Структура по мотивам JHipster — `entities`, `service`, `router`, `shared/model`, `core`, `stores`, `i18n`.

## Требования
- Node.js 22.12+ / npm
- Работающий Spring Boot backend на `127.0.0.1:8080` с PostgreSQL и миграциями Flyway V1–V9; ffprobe нужен для аудио.

## Запуск в VS Code, PowerShell

Терминал №1 (backend) остаётся работающим.
В терминале №2:

```powershell
cd D:\Development\guitar-mentor-ai
git fetch origin
git switch main
git pull --ff-only
cd frontend
npm ci
npm run dev
```

Открой `http://127.0.0.1:5173/`. Vite пересылает запросы `/api` в Spring Boot на `127.0.0.1:8080`. CORS вручную настраивать не нужно.

## Проверка
1. Укажи тестовое имя и выбери LIKE/NEUTRAL/EXCLUDE для стилей.
2. Сохрани профиль. Будет создан Learner в PostgreSQL.
3. Обнови страницу: приложение восстановит сохранённый ID профиля из localStorage и сделает GET.
4. Измени оценку одного стиля и нажми «Сохранить предпочтения»: выполняется PUT, история ученика не теряется.
5. Перейди в «Опыт и цели», укажи техники, разученные композиции и время занятий, сохрани анкету.
6. Обнови страницу и убедись, что сведения восстановились из PostgreSQL.
7. Проверь `npm run build`.

Первая версия не включает редактирование имени, переключение нескольких инструментов или авторизацию.

### Известные ограничения

**Внимание: профиль не защищён авторизацией.** Локальный интерфейс сохраняет UUID ученика в `localStorage` лишь для удобства тестирования. Это не средство аутентификации. Backend привязан к loopback, запрещено публиковать порты 8080/5173 или подключать внешних пользователей. Использовать вымышленные тестовые данные.

Версии npm-зависимостей зафиксированы в `package-lock.json`. GitHub Actions использует `npm ci`; для локальной установки на чистом окружении также рекомендуем `npm ci`.

## Проверка домашней страницы

- Открой `/` без выбранного профиля: видны приветствие, «Начать знакомство» и три карточки разделов.
- Создай тестовый профиль и вернись по логотипу: приветствие и хедер показывают имя; основная кнопка — «Мой профиль». Обновление страницы восстанавливает профиль.
- Проверь все карточки, возврат по логотипу из каждого раздела, переключение RU/EN и узкий экран.
- При недоступном backend главная остаётся доступной; ошибка восстановления профиля позволяет повторить запрос. Удалённый профиль (404) сбрасывает локальный выбор.

## Диагностика и попытки

В main уже доступны назначение GM-EB01 и панель «Моя работа»: файл или микрофон/индикатор/прослушивание черновика/явная отправка, технические статусы и история после F5. При выключенных загрузках чтение истории доступно. MP3/PDF каталога устанавливаются отдельно. [Инструкция аудио](../docs/development/dev-07-local-audio-submission.md), [пакет материалов](../docs/development/dev-06-media-preview.md). Для короткого URL запустить Caddy и открыть https://guitar-mentor/diagnostics; профиль прежнего origin переносится по инструкции Caddy без создания дубликата. Музыкального анализа, решения ученика и TTL пока нет. [Состояние проекта](../docs/project/current-state.md).
