# GM-EB04 — Две дорожки (Two Paths)

**Версия:** 1.0.0 · **Статус:** DRAFT_PENDING_MUSICAL_REVIEW · **Темп:** 76 BPM · **Размер:** 4/4 · **8 тактов** · стандартный строй E2–A2–D3–G3–B3–E4.

Оригинальный двухголосный fingerstyle-этюд: большой палец **p** держит ровные четверти баса; пальцы **i/m** исполняют самостоятельную верхнюю мелодию, часто вступающую между долями. Форма A–A′ (4+4 такта), гармония C–G–Am–F / C–G–F–C. Чередование басовых струн внутри каждого такта; без медиатора и перкуссии.

- [MusicXML v1](two_paths_v1.musicxml): два независимых голоса, точные высоты, длительности, паузы, string/fret в `technical`. Концертные высоты; для гитарной нотной записи в октаву выше потребуется отдельная редакция, а не изменение звучания.
- [JSON v1](score_events_v1.json): `beat` — отсчёт с нуля; `length` — четвертные доли. Явные паузы верхнего голоса, четыре четверти в басовом голосе.
- [Паспорт версии](metadata_v1.json): учебные цели, инструкция, критерии, лицензия и статус.

## Практика и оценка

Начните с одного большого пальца на **55 BPM**, затем добавьте мелодию; первая нота первого такта звучит **на «и» первой доли**. Пульс большого пальца не должен повторять смещения мелодии. Доведите темп до 76 BPM, сделайте бас тише мелодии; ориентир — 15 минут. Проверяйте непрерывность баса, синкопированные вступления без сбоев, чистоту смены гармонии и выделение верхнего голоса. Это **критерии практики, не автоматический результат оценки**.
