# GM-EB01 — «Вечерний блюз в ми»

## v0.4 — полный этюд, 12 тактов (ожидает музыкальной приёмки)

Продолжает одобренный четырёхтактовый прототип **v0.3** (его ноты оставлены без изменения). Оригинальная fingerstyle-миниатюра для акустической гитары, без медиатора и перкуссии, **E7 / A7 / B7**, 4/4, 84 BPM, лёгкое свинговое прочтение восьмых.

**На данном этапе это музыкальный черновик.** Автоматически назначать ученикам **нельзя**, пока автор/гитарист не подтвердит удобство игры и музыкальную привлекательность.

- [Исходные музыкальные события v0.4, JSON](score_events_v04.json)
- [Метаданные и статус v0.4](metadata_v04.json)

### Форма

1–4 — одобренная тема v0.3: E7, E7, A7, E7.

5–8 — развивающий раздел: A7, A7, E7, E7.

9–12 — B7, A7, E7, затем B7 → E7 в последнем такте (разрешение на третьей доле).

**Важно:** это модифицированная 12-тактовая форма с ранним IV7 в третьем такте, а не строго типичная последовательность классического 12-bar blues.

### Исполнение

- Большой палец p ведёт самостоятельный бас; i/m/a берут верхние созвучия и мелодию.
- Восьмые играются с лёгким шаффлом; мелодия громче баса.
- Сначала играть по частям по четыре такта в 60–70 BPM, затем ближе к 84 BPM.
- PDF (3 страницы A4), MIDI и MP3 подготовлены для музыкального ревью в чате; **MP3 синтезирован**, не является записью гитариста.
- В MusicXML есть две нотные системы (ноты и TAB) и два независимых голоса; корректность импорта в MuseScore/Guitar Pro ещё требует проверки.

### Контроль перед выпуском

1. Удобно ли сыграть без неожиданных физических конфликтов пальцев?
2. Хочется ли выучить всю пьесу, а не только первые четыре такта?
3. Есть ли ощущение развития и уместного завершения; не слишком ли однообразен бас?
4. Достоверно ли воспроизводит PDF нотный материал из MusicXML?
5. Только после этого — статус APPROVED и назначение задания через backend.
